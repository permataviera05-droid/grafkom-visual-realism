# 3D Visual Realism Suite (Grafika Komputer - Minggu 11)

Java 17 + LWJGL 3 + JOML + Modern OpenGL 3.3 (GLSL).
Jalankan kelas `com.grafkom.viewing3d.Main` (di macOS tambahkan VM option `-XstartOnFirstThread`).

| Tombol | Fungsi |
|---|---|
| B | Phong <-> Blinn-Phong |
| F | Flat <-> Smooth shading |
| Z | Z-Buffer ON/OFF |
| C | Back-Face Culling ON/OFF |
| T | Tekstur ON/OFF |
| N | Filter Nearest <-> Bilinear+Mipmap |
| H | Bayangan (Shadow Mapping) ON/OFF |
| [ / ] / 0 | Bias bayangan diperkecil / diperbesar / reset |
| L | Cahaya berputar ON/OFF |
| SPACE | Objek berputar ON/OFF |
| W | Wireframe ON/OFF |
| V | VSync ON/OFF |
| Panah, Q/E | Putar kamera, zoom |
| ESC | Keluar |
